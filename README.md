# 자원관리 도우미 (정보통신지원센터)

설치나 인터넷 연결 없이 쓰는 단일 HTML 도구입니다. 외부 글꼴, CDN, 서버를 쓰지 않으며 엑셀 파일도 HTML 안에서 직접 만듭니다.

## 실행 방법

1. `자원관리도우미.html` 파일을 **더블클릭**합니다. (Chrome 또는 Edge 권장)
   - 다른 브라우저로 열리면 파일을 우클릭한 뒤 **연결 프로그램 → Microsoft Edge / Chrome**을 고릅니다.
   - 브라우저 주소창에 파일을 끌어다 놓아도 열립니다.
2. 처음 열면 **샘플 데이터**로 시작합니다(상단에 보라색 `샘플 데이터` 표시). 상단의 **샘플 데이터 초기화**를 누르면 언제든 처음 상태로 돌아갑니다.
   - 실제 업무를 시작할 때는 **빈 데이터로 시작**을 누릅니다. 부서 목록만 남기고 모두 비우며, 홈 화면에 입력 순서 안내가 나옵니다.
   - 실제 데이터를 쓰는 중에 샘플 초기화를 누르면 실수 방지를 위해 `샘플`이라고 직접 입력해야 진행됩니다.
3. 상단에서 **작업자(정 담당자 / 부 담당자)**를 고릅니다. 확인자·담당자 칸의 기본값으로 쓰입니다.

## 데이터 저장과 공유 (두 담당자 운영 규칙)

- **💾 저장**을 누르면 `자원관리_YYYYMMDD_HHMM.json` 파일이 다운로드 폴더에 저장됩니다. 이 파일을 클라우드 공유 폴더에 올립니다.
- **📂 불러오기**로 공유 폴더의 **가장 최근 파일**을 선택하면 전체 데이터가 그 파일 내용으로 바뀝니다. 상단에 저장 일시와 저장자가 표시됩니다.
- 저장하지 않은 변경이 있으면 상단에 `● 저장 안 한 변경 있음`이 표시되고, 창을 닫거나 다른 파일을 불러올 때 경고합니다.
- 이 표시를 누르면 **변경 내역** 창이 열립니다. 마지막 저장·불러오기 이후 무엇이 추가·수정·삭제됐는지(수정은 "이전 → 이후" 값까지) 분류별로 보여주며, 창에서 바로 저장할 수 있습니다.
- 두 사람이 같은 시간에 수정하지 않습니다. 나중에 올린 파일이 앞의 변경을 덮어씁니다. 이전 파일은 지우지 말고 백업으로 남겨 둡니다.
- (편의 기능) 브라우저를 새로 고쳐도 마지막 작업 상태가 이 PC 브라우저에 임시로 남아 있습니다. 다만 공유는 반드시 JSON 파일로 합니다.

## 화면 구성

| 화면 | 내용 |
|---|---|
| ① 홈(알림판) | 반납 기한 초과(빨강)·임박(주황), 구매 소요 확정 대상(주황), 불용 대상(빨강), 사전 검토 대상(노랑, 만료 1~2년 전), 분기 보고 안내, 대여 가능 대수. 항목을 누르면 해당 화면으로 이동 |
| ② 장비·대여 | 대여 가능 대수(모델별), 대여 등록(공문번호 필수)·반납·수정, 대여 이력(장비·부서별, 월 단위 조회기간 — 기본 최근 1년, S/N 표시), 전체 장비 목록(자산번호·모델·S/N·부서·사업명 검색, 필터, 불용처리, 엑셀 양식으로 일괄 등록), 장비모델 관리 |
| ③ 소모품 | 재고(자동 계산), 입고·불출·실사 보정, 월별 불출 현황(품목별/프린터 모델별/수령부서별, 수량·금액, 엑셀 내보내기), 폐토너 관리(1대1 교환 반납·미반납·추가 회수·처리(반출), 엑셀 내보내기), 작년 대비 소모량 비교, 분기 구매 소요표(예산·잔액, 확정 수량 수정, 엑셀 내보내기) |
| ④ 분기 보고 | 총괄현황(모델 단위·소계·합계) / 세부현황(장비 1대 단위), 상태·장비종류 필터, 엑셀 내보내기(총괄현황·세부현황 시트 분리) |
| ⑤ 부서 관리 | 상위부서명·부서명 관리. 부서 추가(한 개/여러 개 붙여넣기 "상위부서, 부서")·수정(상위부서, 부서명 변경 시 기존 기록 일괄 반영, 같은 이름이면 합치기)·삭제, 상위부서별 보기·상위부서명 일괄 변경, 부서별 사용 현황, 목록에 없는 부서명 정리. 상위부서명은 이 화면에서만 표시 |

모든 표는 머리글을 누르면 정렬됩니다. 누를 때마다 오름차순(▲) → 내림차순(▼) → 기본 순서로 바뀝니다. 소계·합계 행은 제자리에 있고, 여러 페이지로 나뉜 표는 전체를 기준으로 정렬합니다.

- 파일은 브라우저의 **다운로드 폴더**에 저장됩니다.
- 보고용 엑셀 파일은 다시 불러올 수 없습니다. 엑셀로 들어오는 것은 **장비 등록 양식**뿐이고, 그 밖의 데이터 수정은 도구 안에서 하세요.
- 기존 엑셀 장비 대장은 장비 등록 양식의 열 순서에 맞춰 복사·붙여넣기하면 한 번에 등록할 수 있습니다.

## 판정 규칙 요약

- 만료일 = 도입일 + 사용연한(년)
- **불용 대상**: 기준일 > 만료일 / **구매 소요 확정 대상**: 기준일 ≤ 만료일 ≤ 기준일 + 1년 / **사전 검토 대상**: 기준일 + 1년 < 만료일 ≤ 기준일 + 2년 (예산·교체 계획 미리 검토)
- 기준일: 홈 화면은 오늘, 분기 보고는 선택한 분기의 마지막 날
- 구매 소요: 1·2분기는 (작년 대당 연간 소모량 × 올해 운영 대수) − 재고, 3·4분기는 (올해 월평균 × 연말까지 남은 개월) − 재고. 올해 안에 불용 대상이 되는 프린터는 운영 대수에서 뺍니다.
